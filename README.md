# One Card Dungeon

Gioco browser vanilla JavaScript ispirato a One Card Dungeon.

## Pubblicazione

Il progetto e predisposto per GitHub Pages tramite il workflow in `.github/workflows/pages.yml`.
Ogni push sul branch `main` pubblica automaticamente il contenuto della cartella.

## Avvio locale

Apri `index.html` con un server statico, per esempio:

```powershell
npx --yes http-server . -p 4173
```
